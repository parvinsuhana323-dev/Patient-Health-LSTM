# Patient-Health-LSTM
Patient Health Time-Series Forecasting Using LSTM
Project Overview

This project focuses on Patient Health Time-Series Forecasting using Long Short-Term Memory (LSTM), a deep learning technique.

The main objective is to predict a patient's next-hour heart rate using previous 24 hours of patient health data.

Project Objectives

- Analyze patient health data.
- Perform data preprocessing.
- Build time-series sequences.
- Develop an LSTM deep learning model.
- Train and evaluate the model.
- Predict future heart rate values.

Technologies Used

- Python
- Jupyter Notebook
- TensorFlow
- Keras
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Dataset Description

The dataset contains patient health information and vital signs such as:

- Heart Rate
- Blood Pressure
- Body Temperature
- SpO2
- Respiratory Rate
- Blood Glucose
- Age and Gender

Model Architecture

The project uses an LSTM-based deep learning model for time-series forecasting.

The model includes:

- LSTM Layers
- Dropout Layers
- Dense Layers
- Adam Optimizer
- Mean Squared Error (MSE) Loss Function

Project Files

1. patient_health_lstm (1).ipynb
2. patient_health_timeseries_lstm.csv
3. patient_hr_lstm.keras

Conclusion

This project demonstrates the application of deep learning techniques for patient health time-series forecasting.

The LSTM model uses historical patient health data to predict future heart rate values.
